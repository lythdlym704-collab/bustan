# 👰 العروسة — لعبة تلبيس ومكياج

لعبة جوال: العروسة تجي وسخة ← تحمّميها ← تلبسينها فستان ← تمكيجينها ← تسشورين شعرها ← تحطين عدسات ← تضغطين **عرض** وتمشي على المسرح.

## طريقة التثبيت على الجوال (عن طريق GitHub Pages)

1. ادخلي على github.com وسوّي حساب (مجاني).
2. اضغطي **+** فوق ← **New repository** ← سمّيه `bride-game` ← خليه **Public** ← **Create repository**.
3. اضغطي **uploading an existing file** وارفعي كل ملفات المجلد (index.html و manifest.json و sw.js ومجلد icons) ← **Commit changes**.
4. روحي **Settings** ← **Pages** ← تحت Branch اختاري **main** ← **Save**.
5. انتظري دقيقة، بيطلع لك رابط مثل: `https://اسمك.github.io/bride-game/`
6. افتحي الرابط من الجوال:
   - **أندرويد (Chrome):** اضغطي زر «📲 ثبّتي اللعبة» أو القائمة ⋮ ← **تثبيت التطبيق**.
   - **آيفون (Safari):** زر المشاركة ⬆️ ← **إضافة إلى الشاشة الرئيسية**.

تطلع أيقونة اللعبة على الشاشة وتشتغل كتطبيق، حتى بدون إنترنت بعد أول مرة.

## (اختياري) ملف APK للأندرويد
بعد رفع الملفات، روحي تبويب **Actions** ← **Build Android APK** ← **Run workflow**.
لما يخلص، افتحي التشغيل ونزّلي `bride-apk` من أسفل الصفحة، فكّي الضغط وثبّتي `app-debug.apk` (لازم تسمحين بتثبيت تطبيقات من مصادر غير معروفة).
